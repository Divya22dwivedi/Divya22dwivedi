## 🔬 Research Experience

### Machine Learning Research Intern | NIT Rourkela

*May 2026 – July 2026*

- Developed ML surrogate models using Random Forest, XGBoost and LightGBM to approximate computationally expensive Aspen Plus simulations.
- Worked with 74,536 simulation data points, achieving R² > 0.999 on test data.
- Applied 5-fold cross-validation and randomized hyperparameter search.
- Optimized the process using Differential Evolution.
- Reduced optimization time from 5,248 seconds to 3.7 seconds (over 99.9% faster), while staying within 0.3% of the optimum.
